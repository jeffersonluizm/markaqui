## Diagrama de Fluxo

O diagrama apresenta o estudo do fluxo de interação do usuário cliente, que utiliza do serviço, e do usuário prestador de serviço, que disponibiliza um horário dentro da aplicação para ser agendado. O Fluxograma apresenta a interação esperada dos diferentes tipos de usuário com a aplicação. O planejamento busca gerar impacto na qualidade no design do wireframe iterativo que será desenvolvido em seguida.
Este diagrama foi desenvolvido no https://app.diagrams.net.
