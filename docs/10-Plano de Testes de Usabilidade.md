# Plano de Testes de Usabilidade

## Definição do(s) objetivo(s)

Os objetivos principais deste teste de usabilidade para o aplicativo Markaqui (aplicativo móvel de agendamento de horários) são:

— Verificar se os usuários conseguem agendar, remarcar e cancelar horários sem dificuldades.
— Avaliar a eficiência do fluxo de navegação entre as telas principais (home → serviços → agenda → confirmação).
— Identificar barreiras nas etapas de cadastro, login e escolha de serviços.
— Avaliar a clareza das informações apresentadas e a consistência da interface.
— Medir a satisfação geral do usuário ao utilizar o aplicativo.
— Verificar a acessibilidade e compreensão da interface por usuários com diferentes níveis de familiaridade tecnológica.

## Seleção dos participantes

Para garantir que o teste reflita o uso real do sistema, escolha participantes representativos do público-alvo.

**Critérios para selecionar participantes:**
Idade entre 18 e 65 anos.
Pelo menos 3 perfis:
— Usuários que já utilizam apps de agendamento.
— Usuários com pouca experiência com tecnologia.
— Profissionais que utilizariam o app com frequência (ex.: clientes de clínicas, salões, academias etc.).
— Diversidade de gênero.

Pelo menos um participante com necessidades especiais leves (baixa visão, por exemplo), se possível.
**Quantidade recomendada:**
Mínimo: 5 participantes.
Ideal: Entre 8 e 12 para maior diversidade.

## Definição de cenários de teste

Os cenários representam tarefas reais que os usuários executam no sistema. Neste projeto, cada grupo deverá definir, no mínimo, **CINCO cenários para a aplicação** e cada cenário deve incluir:

- Objetivo: O que será avaliado.
- Contexto: A situação que leva o usuário a interagir com o sistema.
- Tarefa: A ação que o usuário deve realizar.
- Critério de sucesso: Como determinar se a tarefa foi concluída corretamente.

**Cenário 1 — Agendar um horário**

**Objetivo:** Avaliar se o usuário consegue realizar um agendamento básico de forma rápida e intuitiva.

**Contexto:** O usuário deseja marcar um horário para corte de cabelo amanhã à tarde.

**Tarefa(s):** 
— Abrir o aplicativo e localizar a área de “Serviços”.
— Selecionar “Corte de cabelo”.
— Escolher o profissional e visualizar horários disponíveis.


**Critério(s) de Sucesso(s):**
— Usuário realiza o agendamento sem ajuda.
— Processo concluído em até 2 minutos.
— Nenhum erro grave durante o fluxo (ex.: voltar à tela inicial sem querer).
— Usuário compreende claramente a tela de confirmação.

**Cenário 2 — Remarcar um horário já agendado**

**Objetivo:** Verificar a facilidade do usuário para modificar um agendamento existente..

**Contexto:** O usuário marcou um horário, mas precisa antecipá-lo.

**Tarefa(s):** 
— Acessar o menu “Meus Agendamentos”.
— Selecionar o agendamento existente.
— Escolher a opção “Remarcar”.
— Selecionar um horário e confirmar o agendamento.
— Selecionar um novo horário e confirmar a alteração.

**Critério(s) de Sucesso(s):**
— Usuário encontra a função de remarcar rapidamente.
— Sistema apresenta alternativas de horários disponíveis sem confusão.
— O usuário compreende a confirmação da remarcação.

**Cenário 3 — Cancelar um agendamento**

**Objetivo:** Validar se o cancelamento é facilmente localizável e compreensível..

**Contexto:** O usuário não poderá comparecer ao horário marcado e deseja cancelar.

**Tarefa(s):** 
— Acessar “Meus Agendamentos”.
— Abrir um agendamento.
— Localizar e tocar em “Cancelar Agendamento”.
— Confirmar o cancelamento.


**Critério(s) de Sucesso(s):**
— Função de cancelamento visível e clara.
— Usuário entende as mensagens de aviso (ex.: política de cancelamento).
— Cancelamento concluído com feedback visual adequado.

**Cenário 4 — Criar conta e fazer login**

**Objetivo:** Avaliar a facilidade no cadastro de novos usuários e login.

**Contexto:** Usuário instalou o aplicativo pela primeira vez.

**Tarefa(s):** 
— Acessar a tela de cadastro.
— Inserir nome, e-mail, telefone e senha.
— Confirmar cadastro.
— Fazer login usando os dados cadastrados.


**Critério(s) de Sucesso(s):**
— Processo de cadastro concluído sem erros.
— Validações de dados funcionam corretamente (ex.: senha fraca, e-mail inválido).
— Login concluído sem necessidade de refazer etapas.

**Cenário 5 — Navegar pelos serviços e buscar por um serviço específico**

**Objetivo:** Verificar clareza na organização da lista de serviços.

**Contexto:** O usuário deseja encontrar um serviço específico: “Massagem relaxante”.

**Tarefa(s):** 
— Acessar o menu de serviços.
— Navegar pela lista ou utilizar a busca interna.
— Localizar “Massagem relaxante”.
— Visualizar detalhes do serviço e preço..

**Critério(s) de Sucesso(s):**
— Serviço encontrado em até 30 segundos.
— Usuário entende as categorias e filtros.
— Tela de detalhes é clara e objetiva.



## Métodos de coleta de dados

Os seguintes métodos serão utilizados:

**Métricas quantitativas**

— Tempo para completar cada tarefa.
— Número de toques/cliques até concluir o objetivo.
— Quantidade de erros cometidos.
— Número de vezes em que o usuário pediu ajuda.

**Métricas qualitativas**

— Comentários espontâneos do usuário durante o teste (think-aloud).
— Observação de expressões de frustração, dúvidas ou facilidade.
— Notas de satisfação pós-teste (escala Likert 1–5).
— Questionário pós-teste (exemplos)
— A interface foi fácil de usar?
— Você encontrou alguma dificuldade em alguma etapa?
— O que mais gostou no aplicativo?
— O que menos gostou?
— Recomendaria este aplicativo para outra pessoa?

**LGPD**

Nenhum dado pessoal identificável será registrado.
**Participantes serão referenciados como:** Usuário 1, Usuário 2, Usuário 3...
